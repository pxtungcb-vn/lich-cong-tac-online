Chọn file "THÔNG BÁO lịch công tác của Thường trực Tỉnh uỷ" đúng mẫu đang dùng (file Word hoặc file PDF). Hệ thống sẽ tự động đọc và điền vào các ô bên dưới — bạn xem lại, chỉnh sửa nếu cần rồi bấm "Lưu lịch công tác tuần này" như bình thường. Dữ liệu sẽ được điền vào tuần đang mở hiện tại (hoặc tự chuyển sang đúng tuần nếu file có ghi rõ ngày).
